# 🌍 Wanderlust – Travel Listings Web Application

Wanderlust is a **full-stack travel listing web application** where users can explore, create, update, and manage travel destinations.  
It is inspired by platforms like Airbnb and focuses on **real-world CRUD operations, authentication, search, and deployment**.

🔗 **Live Demo:**  
https://wanderlust-travel-platform-s5gu.onrender.com/listings

---

## 🚀 Features

- 🏠 Create, Read, Update, Delete (CRUD) travel listings  
- 👤 User authentication & authorization  
- 🔐 Secure login and signup system  
- 🖼️ Image upload for listings  
- 📍 Location-based travel listings  
- 🔍 Advanced search and filters  
- 🧑‍💻 Server-side rendering with dynamic content  
- 🌐 Fully deployed application

## ⚙️ Installation & Setup

Follow these steps to run the project locally:

### 1️⃣ Clone the repository
```bash
git clone https://github.com/your-username/wanderlust.git
cd wanderlust

2️⃣ Install dependencies
npm install

3️⃣ Setup environment variables
Create a .env file and add:
MONGO_URI=your_mongodb_connection_string
CLOUDINARY_CLOUD_NAME=your_cloud_name
CLOUDINARY_API_KEY=your_api_key
CLOUDINARY_API_SECRET=your_api_secret
SESSION_SECRET=your_secret_key

4️⃣ Run the application
npm start
The app will run on:
http://localhost:3000
